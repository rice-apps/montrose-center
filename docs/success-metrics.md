# Success metrics

Agree on a baseline period, reporting period, data owner, and source for each measure before implementation.

| Measure | Definition to confirm |
| --- | --- |
| Internal referrals | Created, accepted, and completed counts reported separately |
| Service usage | Actual delivered services, not directory views or referrals alone |
| Wait time | Explicit start and end events, such as submission to first appointment |
| Total clients | Unique clients within a reporting period and an agreed deduplication method |

Confirm how these measures can be linked to existing records without collecting unnecessary data. Capture workflow timestamps needed for agreed reporting. Restrict reports that might expose client information.
